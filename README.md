# Сделки по корпусам и планировкам

Интерактивная визуализация продаж квартир ЖК «Монблан на Павелецкой» за март–сентябрь 2026 года.

Откройте `index.html` в браузере. Интернет и установка зависимостей не нужны.

## Как читать

- Шесть колонок соответствуют корпусам. Блоки выровнены снизу.
- Комнатность и площадь увеличиваются снизу вверх.
- Цветная плитка представляет завершённую сделку. Цвет показывает длительность от обращения до продажи: до 10 дней, 11–20 дней или от 21 дня.
- Серая плитка обозначает квартиру без зарегистрированной сделки.
- Цифра внутри плитки — этаж. Жёлтый уголок — наличие скидки.
- Каждый цвет занимает отдельную строку. Внутри строки сделки со скидкой собраны вместе, этажи возрастают слева направо внутри каждой группы скидки.
- Наведение или нажатие на плитку показывает подробности. Нажатие вне плитки или Escape закрывает подсказку.

Размер плиток подстраивается под окно. В очень небольших окнах читаемость ограничена объёмом данных.

## Данные

Источник: «Продажи ЖК, март–сентябрь 2026.xlsx», лист `full`. Визуализация содержит 367 квартир, из них 248 с зарегистрированной продажей и 119 без сделки.

Отсутствие сделки не раскрывает текущий статус переговоров и дату начала продажи. Длительность сделки не равна полному сроку экспозиции. Наблюдаемые различия не доказывают причинное влияние характеристик квартиры.

Данные встроены в `index.html`; их редактируемая копия находится в `data/sales.json`. После обновления JSON запустите:

```sh
python3 scripts/embed_data.py
```

Репозиторий содержит цены, суммы сделок и имена менеджеров. По умолчанию предназначен для приватного хранения.
